# Visual Tutor App

A multimodal AI education application that uses Gemini 3.0 Pro for reasoning and Nano Banana Pro for high-fidelity explanatory diagram generation. Students can snap/annotate photos of confusing concepts or use live camera feed with Gemini Live for real-time visual explanations.

## Features

- **Snap & Annotate**: Take photos, draw annotations (circles, arrows, text), and get AI-generated visual explanations
- **Live Lens**: Real-time video streaming with AI analysis and on-demand diagram generation
- **Visual Explanations**: High-quality educational diagrams generated by Nano Banana Pro
- **Intelligent Tutoring**: Gemini 3.0 Pro analyzes confusion points and crafts personalized explanations

## Tech Stack

- **Backend**: Python FastAPI with async/await
- **Frontend**: React + TypeScript + Vite
- **State Management**: Redux Toolkit
- **AI Models**: Gemini 3.0 Pro, Nano Banana Pro
- **Real-Time**: WebSocket for Gemini Live

## Getting Started

### Prerequisites

- Python 3.11+
- Node.js 18+
- API keys for Gemini and GenSpark

### Backend Setup

```bash
cd backend
python -m venv venv
source venv/bin/activate  # On Windows: venv\Scripts\activate
pip install -r ../requirements.txt
cp ../.env.example .env
# Edit .env with your API keys
uvicorn main:app --reload
```

### Frontend Setup

```bash
cd frontend
npm install
npm run dev
```

## API Endpoints

### REST API

- `POST /api/v1/snap-and-explain` - Upload annotated image for explanation
- `GET /api/v1/health` - Health check endpoint

### WebSocket

- `WS /api/v1/live-lens` - Real-time video streaming and analysis
